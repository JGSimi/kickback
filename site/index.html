Como instalar

  1. Arraste para Aplicativos

    Abra o KickBack.dmg baixado e arraste o KickBack para a pasta Aplicativos.

  2. Abra o app

    O KickBack é notarizado pela Apple e abre direto. Em Macs com Apple Silicon ele precisa do Rosetta 2; se faltar, o app avisa e mostra o comando:

    softwareupdate --install-rosetta --agree-to-license

  3. Crie uma garrafa e jogue

    A garrafa é um “PC Windows” isolado. Arraste o instalador do jogo para a janela; depois de instalado, ele aparece na lista para abrir com um clique.

O que vem dentro

DirectX 9 a 12
DXVK e DXMT já vêm no app. Para DirectX 12, importe o D3DMetal do Game Porting Toolkit da Apple, que é grátis.
Vídeos dos jogos
Cenas em vídeo tocam com decodificação por hardware do Mac (GStreamer com VideoToolbox).
Controles
Controles de Xbox, PlayStation e outros funcionam pelo SDL2.
Cada jogo no seu canto
Garrafas separadas evitam que um jogo quebre outro. Excluir uma garrafa manda tudo para a Lixeira.
Instaladores sem surpresa
.NET e o motor de páginas web do Windows já vêm embutidos, sem downloads extras durante a instalação.
Código aberto
Usa o mesmo Wine que a CodeWeavers publica para o CrossOver 26.3. Todo o build é reproduzível a partir do repositório.

Dúvidas

É grátis mesmo?

Sim. O código do KickBack é MIT e todos os componentes são de código aberto. Não há assinatura nem versão paga.

É o CrossOver?

Não. O KickBack usa o mesmo Wine de código aberto que a CodeWeavers publica, mas não é afiliado a ela e não inclui a base de compatibilidade por jogo do CrossOver, que é paga. Se você quer suporte oficial, o CrossOver é o produto da CodeWeavers.

Meu jogo vai rodar?

Muitos jogos DirectX 9, 10 e 11 rodam. Jogos com anti-cheat em nível de kernel, como Valorant e Fortnite, não rodam em nenhuma solução baseada em Wine. Se um jogo der problema, troque a opção de Gráficos da garrafa e teste de novo.

Funciona no meu Mac?

Precisa do macOS 13 ou mais novo. Foi testado em Apple Silicon (M1). Nesses Macs o Rosetta 2 é obrigatório; o app avisa e mostra o comando para instalar.

É seguro?

O app é assinado com Developer ID e notarizado pela Apple, que verifica o pacote antes de liberar. O código está todo no GitHub para quem quiser conferir ou compilar.

KickBack é um projeto independente de código aberto. Não é afiliado à CodeWeavers nem à Apple. CrossOver é marca registrada da CodeWeavers, Inc.; Windows e DirectX são marcas da Microsoft.
